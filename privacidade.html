Política de Privacidade

Última atualização: 18 de novembro de 2026.

O aplicativo "Canal Reliquias" é uma ferramenta interna do canal Relíquias do Passado. Ele é usado somente pelo responsável pelo canal para enviar vídeos e editar os dados (título, descrição, miniatura e legendas) dos vídeos do próprio canal no YouTube.

Serviços de API do YouTube

O Canal Reliquias usa os Serviços de API do YouTube. Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

Dados acessados

Com a autorização da conta do canal (OAuth), o aplicativo acessa apenas: as informações básicas do próprio canal (nome e ID), para confirmar que está agindo no canal certo; e os vídeos que ele mesmo envia, para definir miniatura e legendas. Ele não acessa dados de outros usuários do YouTube nem de quem assiste aos vídeos.

Como os dados são usados

Os dados servem só para enviar e programar os vídeos do canal. Não são usados para publicidade, análise de terceiros ou qualquer outra finalidade.

Armazenamento e compartilhamento

O aplicativo guarda somente o ID de cada vídeo que ele enviou, em um registro privado. O token de acesso fica guardado de forma criptografada no ambiente privado que produz os vídeos. Nenhum dado é vendido nem compartilhado com terceiros.

Exclusão de dados e revogação do acesso

O acesso do aplicativo pode ser revogado a qualquer momento na página de permissões da Conta do Google: myaccount.google.com/permissions. Depois da revogação, ou a pedido pelo e-mail abaixo, os dados guardados (token e registro de IDs) são apagados em até 7 dias. Dados obtidos da API que não estiverem mais em uso são apagados ou atualizados em até 30 dias, como exigem as políticas do YouTube.

Cookies

Este site e o aplicativo não usam cookies nem rastreamento.
