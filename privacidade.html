Política de Privacidade

Última atualização: 18 de novembro de 2026.

O aplicativo "Canal Reliquias" é uma ferramenta interna do canal Relíquias do Passado. Ele é usado somente pelos responsáveis pelo canal para enviar vídeos e editar os dados (título, descrição, miniatura) dos vídeos do próprio canal no YouTube.

Dados acessados

Com a autorização da conta do canal, o aplicativo usa a API de Dados do YouTube para enviar vídeos e gerenciar as informações dos vídeos desse canal. Ele não acessa dados de outros usuários do YouTube nem de quem assiste aos vídeos.

Uso e armazenamento

As credenciais de acesso ficam guardadas de forma privada no ambiente que produz os vídeos e servem só para essa finalidade. Não vendemos, compartilhamos nem usamos esses dados para publicidade.

Serviços do Google

O uso das APIs do YouTube segue os Termos de Serviço do YouTube e a Política de Privacidade do Google. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
